# Бот куратора Віктора

Telegram-бот для бізнес-акаунта (Telegram Business → Чат-боти).

## Що вміє зараз
- бачить усі повідомлення в бізнес-чатах Віктора — вхідні й вихідні — і записує їх у базу;
- ділить клієнтів на **нових** (написали «бонус») і **старих** (усі інші);
- на слово «бонус» один раз надсилає клієнту привітання від імені Віктора;
- клієнт відповів на привітання → у групу «💬 … відповів — ваша черга» з текстом відповіді;
- не відповів 2 години → нагадування (`bot/texts.py` → `REMINDER_TEXT`);
- усі повідомлення клієнтам — лише з 7:00 до 20:30 за Києвом (вночі чекають ранку);
- не встиг за 24 години (обмеження Telegram) або клієнт мовчить і після нагадування —
  клієнт з'являється в ранкових задачах Віктора; якщо Віктор пише сам — бот нічого не надсилає;
- пише в Google Таблицю вкладки «Повідомлення», «Клієнти», «Задачі» (невиконані) і «Виконані задачі»;
- щодня о 7:00 (Київ) надсилає в групу «Задачі куратора» 20 клієнтів, з якими найдовше
  (10+ днів) не було діалогу; задача виконана, щойно Віктор напише клієнту;
- обходить базу «колами»: у колі всі інвестори (без партнерів, холодних, «не клієнтів»);
  пройдений = Віктор написав від початку кола; коли пройдено всіх — «🎉 Усіх пройдено» і нове коло;
- не включає в задачі команду (`bot/texts.py` → `TEAM_USERNAMES`) і тих, кому в таблиці
  «Клієнти» поставили позначку в стовпці «Не клієнт» (так / ✅ / x / галочка);
- переводить клієнтів у партнери з групи задач: `/partner Ім'я` → кнопка з клієнтом
  (повернути: `/investor Ім'я`); вкладка «Партнери» + у «Клієнтах» стовпці «Статус» і «Партнер з»;
- «холодні» клієнти: `/cold 3 7 @ivan` (номери зі списку, @username, ім'я або посилання на чат) —
  більше не потрапляють у задачі, бот їм не пише; `/warm` — повернути; вкладка «Холодні»;
- вкладка «Діаграми ефективності» (раніше «Статистика») (оновлюється кожні 10 хв): склад клієнтів, робота куратора за
  сьогодні / вчора / 7 / 30 днів / весь час, тренди по днях і тижнях і 9 діаграм (ріст чи спад);
- вкладка «Ефективність куратора»: швидкість відповіді й хто чекає відповіді, воронка
  бонус → відповів → партнер, якість дотиків, стан бази й прогноз кола, партнери по колах,
  коли працює куратор (оновлюється кожні 10 хв, з оформленням);
- курс інвестора: тему визначає за посиланням на YouTube у повідомленні Віктора (або фразою) —
  `bot/texts.py` → `COURSE_TOPICS`; етап і дата в «Клієнтах»; вкладка «Етапи клієнтів» (✅ / ❌ / ➖);
  вкладка «Ефективність клієнта» (воронка, днів на тему, де пропадають, 3 діаграми);
  «пропав після теми N» (2 дні тиші, `LOST_AFTER_DAYS`) — у групу й у ранкові задачі;
  переглядає всю збережену й імпортовану історію при запуску та після імпорту;
- у «Задачах» видно текст дотику та чи відповів клієнт — для контролю якості;
- імпорт старих чатів: адмін або Віктор надсилає боту в особисті `result.json`
  (експорт Telegram Desktop, формат JSON, «Особисті чати») або zip з ним до 20 МБ;
- щодня о 3:00 (Київ) робить бекап бази й надсилає його лише `BACKUP_CHAT_ID` (за замовчуванням —
  першому з `ADMIN_CHAT_ID`); 7 копій на диску; відновлення — надіслати файл `kurator-backup-….zip` боту;
- `/coursecheck` (адміни) — скільки тем бот упізнав у переписках і які відео YouTube йому невідомі;
- команди: `/id`, `/chatid`, `/tasks`, `/partner`, `/investor`, `/stats`, `/import`, `/status` (для адміна);
- повідомляє адміна про запуск, підключення/відключення бізнес-акаунта і помилки.

## Змінні Railway
| Назва | Обов'язкова | Що це |
|---|---|---|
| `BOT_TOKEN` | так | токен від BotFather |
| `DB_PATH` | так | `/data/bot.db` (база на диску Volume) |
| `GOOGLE_SHEET_ID` | так | ID Google Таблиці |
| `GOOGLE_CREDENTIALS_JSON` | так | увесь JSON сервісного акаунта |
| `ADMIN_CHAT_ID` | бажано | Telegram ID адмінів (з команди `/id`), кілька — через кому: `123456789, 987654321`. Сюди йдуть сповіщення |
| `WELCOME_TEXT` | ні | інший текст привітання замість вбудованого (вбудований — у `bot/texts.py`); новий рядок — `\n` |
| `BONUS_KEYWORDS` | ні | кодові слова через кому, за замовчуванням `бонус` |
| `CURATOR_NAME` | ні | як підписувати повідомлення куратора в таблиці, за замовчуванням `Віктор` |
| `TIMEZONE` | ні | часовий пояс для дат і розкладу, за замовчуванням `Europe/Kyiv` |
| `TASKS_CHAT_ID` | бажано | ID групи «Задачі куратора» (з мінусом). Без неї задачі йдуть адмінам |
| `TASKS_TIME` | ні | о котрій надсилати задачі, за замовчуванням `07:00` |
| `TASKS_PER_DAY` | ні | скільки задач на день, за замовчуванням `20` |
| `TASKS_MIN_DAYS` | ні | мінімум днів без контакту, за замовчуванням `10` |
| `SEND_FROM` / `SEND_UNTIL` | ні | коли бот може писати клієнтам, за замовчуванням `07:00` / `20:30` |
| `REMINDER_DELAY_MINUTES` | ні | через скільки хвилин без відповіді нагадувати, за замовчуванням `120` |
| `REMINDER_TEXT` | ні | інший текст нагадування замість вбудованого |
| `BACKUP_CHAT_ID` | ні | кому надсилати бекап (за замовчуванням — перший ID з `ADMIN_CHAT_ID`) |
| `BACKUP_TIME` | ні | коли робити бекап, за замовчуванням `03:00` |
| `EXCLUDED_USERNAMES` | ні | замінює список команди з `bot/texts.py`, через кому |
